Editor de dibujos pixelados para MiniExcel

Diseña el modelo exacto pintando los cuadritos. Este editor no cambia tu proyecto todavía: genera una matriz JSON para integrar después. El modelo y el tablero del juego deben salir de esa misma matriz.

Cuadrícula de 12 × 12. Haz clic en las celdas para pintar. El color blanco significa “dejar en blanco”, no se cuenta como objetivo de color.

Celdas coloreadas: 0

Cuando los dibujos estén listos, comparte el JSON generado o el archivo descargado junto con el ZIP actual de PequeMundo Digital. Así se puede integrar sin reconstruir los patrones a mano.
